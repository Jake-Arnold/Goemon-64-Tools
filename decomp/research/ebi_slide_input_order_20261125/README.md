## Eligibility gate (priority 1)
JP 801E252C / USA 801DD114 branches agree apart from region calls. Character selector task+60. Ebisumaru index 1 first calls spatial eligibility wrapper JP 801ED718 / USA 801E864C (accepted C). Failure emits 0x3AC and returns zero. Wrapper reads task+18 object fields +8/+C/+10 and calls spatial helper JP 801ED660 / USA 801E8560: Y+6 and Y+18.5 queries against sentinel 0x7FFF, additional query with 7.0; USA additional secondary path. Geometry semantics unresolved. Ebisumaru accepts context+86 == FFFF, action task+CC == 42, task+38 == 0, or falls through to common character 0/2 test requiring FFFF, action 0..3 and task+38 zero. Character 3 instead requires FFFF, action AE, context+59 high bit set or zero, task+38 zero. Out-of-range machine code returns selector byte; C preserves defined return. Action 0D is not directly eligible; sampled recording can miss intermediate state.

## Input dispatch (priority 2)

Literal bit mapping verified; held/pressed-edge interpretation unproved. Activation gate separately permits action 42 or 0..3 in context+86 == 0 path subject to predicates.
