# Japanese rev-0: seven genuinely new small C functions

**21 November 2026.** Sources are independently original-address exact with SGI IDO 5.3 `-O2 -mips2`, and staged atop the *published* JP2282 original-C baseline, without replacing other C sources or changing original ASM section boundaries. All seven passed full Japanese original-ROM G2, original ELF identities and semantic relocations, retail recompression, inventory, 4 task-specific tests, 1,000 original-C host cases, and full local CI.

The target list, original expanded-ROM offsets, code lengths, original instruction SHA-256, source SHA-256, and expected relocations are frozen in `manifest.json`. Functions: byte-threshold checks `func_801D7854_645D44` and `func_801DDC04_64C0F4`; direct multi-field setters `func_8021DAEC_5D907C`, `func_8021DB00_5D9090`; zeroing a float triplet `func_8021FDA4_5DB334`; floating-point/short setters `func_802291F8_6928E8` and `func_8022950C_692BFC`. Original instruction bytes total **156**. No new symbolic relocations are generated by this set.

**Audited deduplication:** three additional 16-byte floating-point setter C sources were byte-exact in exploratory probes, but `func_80215430_69CB30`, `func_802156E4_69CDE4` and `func_80217928_69F028` are already included in JP2268 (145-function publication). The current full owner validation correctly rejected all three as **not ASM-owned**. They are **not** part of this seven-function batch and do not increase the count.

Previous 12-byte SDK `__osSpSetStatus` remains ASM because its numeric C loses original `R_MIPS_HI16/LO16` relocations (issue #158). Other C nonmatches remain research-only, not eligible for promotion.

## Reproduce

With the user's original rev-0 Japanese retail ROM, pinned clean `mnsg` checkout, original IDO 5.3/MIPS binutils and portable Python toolchain, from the toolkit repository:

```bash
bash decomp/build_japan_tiny7_promotion.sh <fresh-pinned-mnsg> <goemon-dependencies> <goemon-runtime-additions>
python3 -m unittest decomp.test_japan_tiny7_promotion -v
python3 -m decomp.local_ci
```

Keep ROMs, decompressed assembly, generated binaries, original compiler and runtime archives private. The adapter rejects modified source hashes, original ROM hash mismatches, overlap, missing ASM owner, changed relocations, changed original ELF identities, altered complete-ROM bytes or incorrect C/ASM partition.
