# Japanese executable symbol reconciliation: full function bounds

This is a **research-only** program that reconciles unique USA→Japanese direct-JAL anchors against original USA N64Recomp symbols. It checks the **entire original function length**, not just the first 16 instructions, and rejects stale or fabricated source addresses.

## Provenance

- Original USA symbol table: `klorfmorf/Goemon64RecompSyms/mnsg.syms.toml`, GitHub blob SHA `fc8f10018165cc2c1f0fc67f98ca3b27928fd5bc`, 7,376 original functions across 72 sections.
- Original section layouts: `klorfmorf/mnsg/config/usa/splat.yaml` and `config/japan_0/splat.yaml`.
- Exact decompressed ROM SHA-1s: USA `6ea0ed71032ce08fc2745f412d84936382197494`, Japanese revision 0 `6f8745fecc3a5e7d4918c7a73353eb0726116ded`.
- Prior JAL report: generated by `decomp.japan_overlay_entrypoints` with 69 common executable regions and 1,922 unique 16-instruction structural anchors.
- Committed metadata subset `decomp/data/impact_usa_227_symbols.toml`: the **227 original `.file_13` symbol entries** corresponding to the prior JAL anchors; retains their original names, VRAM entrypoints, and function sizes. It contains no ROM code.

## Run against the entire original symbols file

```bash
python3 -m decomp.japan_symbol_reconciliation \
  /path/to/usa.decompressed.z64 /path/to/japan.decompressed.z64 \
  --us-splat /path/to/mnsg/config/usa/splat.yaml \
  --jp-splat /path/to/mnsg/config/japan_0/splat.yaml \
  --us-symbols /path/to/Goemon64RecompSyms/mnsg.syms.toml \
  --jal-candidates /path/to/japan_full_overlay_jal_candidates.json \
  --output /tmp/japan_reconciled_functions.json
```

To reproduce just the audited `.file_13` subset, filter the 1,922-candidate JSON to rows with `section == '.file_13'` before invoking this program and use the checked-in `--us-symbols decomp/data/impact_usa_227_symbols.toml`. The program rejects unrecognised sections rather than silently skipping unmatched sections.

## Verified Impact `.file_13` integration

| Property | Result |
| --- | ---: |
| Original USA symbol functions in the audited subset | 227 |
| Unique candidate anchors confirmed at known function entries | 227 |
| Entire-function normalized MIPS structural matches | **177** |
| Too short for independent 16-instruction qualification | 50 |
| Full structural matches that are byte-for-byte identical | **11** |
| Total original function bytes covered by the 177 | **59,036** |
| Exactly identical machine instruction words in the 177 | **13,686 / 14,759** |
| Complete structural mismatches for candidates of at least 16 words | 0 |

The original symbol table has 1,000 functions in `.file_13`. The other 773 weren't included in these direct-JAL candidate matches. This audit does **not** claim coverage of the entire Impact overlay, all N64Recomp symbols, relocated control-flow semantics, or Japanese gameplay.

Classification is intentionally conservative: full structural equality masks MIPS I-format immediates, branch offsets and J/JAL targets. Original USA symbol function lengths are used as a comparison bound, but independent Japanese function boundaries still need verification. No complete Japanese `syms.toml` is emitted.

## Tests and integration status

Eight new ROM-free tests cover complete matches, internal opcode mismatches, forged addresses, non-unique anchors, short functions, unmatched symbol starts, duplicates, and hash mismatches. **34/34 local Python tests passed** across the previous decomp-ROM research suite and these eight. Against the two verified original decompressed ROMs, the 227-symbol Impact subset produces the numbers above.

No actual N64Recomp Japanese executable was compiled, started or played. Complete Goemon64Recomp native savestates remain a separate unimplemented runtime task. This code and the static metadata are safe to review on GitHub; no ROM or game asset files are committed.
