# Retained toolkit ROM research

This directory is not a matching-C source tree. It retains the existing read-only Plasma condition/writer and pickup-placement analyzers, plus their five published metadata reports, because the toolkit's story-flag and placement regressions use them. These reports retain their original content and provenance. No new address discovery or runtime permission is implied.

The complete original toolkit snapshot, including its old `decomp/` code and proof, is preserved at [dae81a7](https://github.com/Jake-Arnold/Goemon-64-Tools/tree/dae81a70fc6e4adf22f76846d202253d3f201b2d/decomp). Current matching-C work belongs exclusively to [stable/decomp](https://github.com/Jake-Arnold/Goemon-64-Tools/tree/stable/decomp). No code was merged between branches.
